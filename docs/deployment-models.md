# รุ่นการติดตั้ง D-Contact สำหรับทีมขาย

สถานะ: **ร่างแรก ยังไม่มีราคาและต้นทุนจริง** owner ยืนยันโครงเมื่อ 11 พฤศจิกายน 2569 สเปกเครื่องของ Duo และ Solo เป็นค่าประมาณที่ยังไม่ได้ load test และ Cluster ยังไม่มีสเปก จึงยังใช้ตัวเลขในเอกสารนี้ออกใบเสนอราคาไม่ได้จนกว่าจะปิดหัวข้อ "ต้องทำก่อนเปิดขาย"

เอกสารนี้เป็นแบบที่เก็บไว้อ้างอิง owner ยืนยันเมื่อ 11 พฤศจิกายน 2569 ว่ายังไม่เริ่มแผนขึ้นระบบจริง ไม่เปิด issue ติดตาม และจะเริ่มทดสอบเมื่อ owner แจ้งว่าพร้อม

แบบเทคนิคของทุกรุ่นอยู่ใน [voice-network-deployment.md](voice-network-deployment.md) และการตัดสินใจหลักอยู่ใน [ADR-038](adr/038-single-voice-stack-tenant-trunks.md)

## สองแกนของการขาย

- **รุ่นการติดตั้ง** บอกว่าระบบรันที่ไหนและทนเครื่องดับได้แค่ไหน: Cloud, Cluster, Duo, Solo (เอกสารนี้)
- **แพ็กเกจความสามารถ** บอกว่าเปิดโมดูลใดบ้าง: Starter, Growth, Enterprise ตาม [licensing.md](licensing.md)

สองแกนขายคู่กัน เช่น Duo + Growth ทุกรุ่นใช้ซอฟต์แวร์ชุดเดียวกัน ความสามารถจึงไม่ต่างกันตามรุ่นการติดตั้ง

## สเปกเครื่องขั้นต่ำของรุ่น on-prem

ใช้ทั้งเป็นสเปกที่ลูกค้าต้องจัดหา และเป็นฐานของราคารวมเครื่อง ตัวเลขเป็นค่าประมาณที่ยังไม่ได้ load test

| | Duo (ต่อเครื่อง จำนวน 2 เครื่อง) | Solo (1 เครื่อง) |
| --- | --- | --- |
| CPU | 16 core | 16 core |
| RAM | 64 GB | 32 GB |
| ดิสก์ใช้งานได้หลัง RAID | 4 TB ขึ้นไป | 2.5 TB ขึ้นไป |
| ในนั้นเป็นไฟล์เสียง 90 วัน | ราว 2.9 TB | ราว 1.5 TB |
| RAID | ทนดิสก์เสียได้หนึ่งลูก | ทนดิสก์เสียได้หนึ่งลูก |
| เครือข่าย | พอร์ตสำหรับ voice, app/data, mgmt และสายตรงระหว่างสองเครื่อง | พอร์ตสำหรับ voice, app/data, mgmt |
| ระบบไฟล์ | ZFS ทั้งสองเครื่อง | ไม่บังคับ |
| ที่เก็บสำรองนอกเครื่อง | ต้องมี | ต้องมี |
| UPS | ต้องมี | ต้องมี |

ดิสก์ส่วนที่ไม่ใช่ไฟล์เสียง (VM ฐานข้อมูล และส่วนเผื่อ) เป็นค่าประมาณของผู้เขียน ยังไม่ได้วัด Cluster ไม่มีสเปกมาตรฐาน ต้องออกแบบและ load test รายลูกค้า

## นโยบายมาตรฐานที่รวมในทุกรุ่น

- บันทึกเสียงทุกสาย เก็บ 90 วัน การเก็บนานกว่านี้เป็นส่วนเพิ่มที่ต้องเพิ่มดิสก์
- นโยบายนี้ขึ้นกับงานบันทึกเสียง retention และการเล่นย้อนหลัง (#845–#848) ซึ่งยังพักอยู่ใน backlog #888 ทุกรุ่นยังส่งมอบตามข้อนี้ไม่ได้จนกว่างานชุดนั้นเสร็จ
- เพดานไฟล์เสียงคิดจากสายเต็มตลอด 8 ชั่วโมงต่อวัน เก็บเป็น WAV mono 8 kHz ลูกค้าที่เปิดเกิน 8 ชั่วโมงต่อวันต้องคิดดิสก์เพิ่มตามสัดส่วน

## โครงราคา

### รุ่น on-prem (Cluster, Duo, Solo)

ทุกรุ่นมีสองราคาให้เลือก: **ซอฟต์แวร์อย่างเดียว** (ลูกค้าจัดหาเครื่องตามสเปกขั้นต่ำ) และ **รวมเครื่อง**

| รายการ | หน่วย | Cluster | Duo | Solo |
| --- | --- | --- | --- | --- |
| ค่าฐานต่อไซต์ | ต่อปี | รอกำหนด | รอกำหนด | รอกำหนด |
| ค่าต่อ Agent | ต่อ Agent ต่อปี ตามแพ็กเกจความสามารถ | รอกำหนด | รอกำหนด | รอกำหนด |
| เครื่อง (เฉพาะราคารวมเครื่อง) | ครั้งเดียว | รายลูกค้า | รอกำหนด | รอกำหนด |
| เก็บเสียงเกิน 90 วัน | ส่วนเพิ่ม | รอกำหนด | รอกำหนด | รอกำหนด |

ค่าฐานต่อไซต์รวม:

- ติดตั้งครั้งแรกตั้งแต่ Proxmox ขึ้นไป
- ดูแลรายปีในเวลาทำการ
- เราสลับเครื่องและกู้คืนให้ทางไกล ซึ่งต้องมีช่องทางเข้าไซต์ลูกค้า เช่น VPN
- ไซต์ที่ตัดอินเทอร์เน็ต ลูกค้าสลับเครื่องเองตามคู่มือ

ไม่รวมในค่าฐาน: การรับเหตุนอกเวลาทำการ ค่า trunk และเบอร์ของลูกค้า และที่เก็บสำรองนอกเครื่อง

### D-Contact Cloud

| รายการ | หน่วย | ราคา |
| --- | --- | --- |
| ค่าต่อ Agent | ต่อ Agent ต่อเดือน ตามแพ็กเกจความสามารถ | รอกำหนด |
| ค่าเบอร์ | ต่อเบอร์ต่อเดือน | รอกำหนด |
| ค่าโทร | ต่อนาทีที่ใช้จริง | รอกำหนด |
| เก็บเสียงเกิน 90 วัน | ส่วนเพิ่ม | รอกำหนด |

ค่าเบอร์และค่าโทรแยกบรรทัดจากค่าต่อ Agent ลูกค้าที่นำ trunk ของตัวเองมาเชื่อมไม่มีสองบรรทัดนี้ โครงค่าฐานต่อไซต์ใช้กับรุ่น on-prem เท่านั้น ยังไม่ได้ตัดสินว่า Cloud มีค่าแรกเข้าหรือไม่

## ต้นทุนที่ต้องเก็บตัวเลข

| ต้นทุน | Cloud | Cluster | Duo | Solo |
| --- | --- | --- | --- | --- |
| เครื่องและดิสก์ | cloud ต่อเดือน | รายลูกค้า | 2 เครื่องตามสเปก | 1 เครื่องตามสเปก |
| Trunk และเบอร์จาก provider ของเรา | มี | ไม่มี | ไม่มี | ไม่มี |
| แรงงานติดตั้ง | ต่อ tenant | ต่อไซต์ | ต่อไซต์ | ต่อไซต์ |
| แรงงานดูแลรายปี | รวมศูนย์ | ต่อไซต์ | ต่อไซต์ รวมการสลับเครื่อง | ต่อไซต์ รวมการกู้คืน |
| การรับประกันและอะไหล่ (ราคารวมเครื่อง) | ไม่มี | มี | มี | มี |

ยังไม่มีตัวเลขในตารางนี้สักช่อง ต้องได้จากฝ่ายจัดซื้อ provider และทีมติดตั้ง

## สิ่งที่ทีมขายต้องบอกลูกค้าให้ชัด

- **Solo ไม่มีเครื่องสำรอง** เมื่อเครื่องดับ ทั้งระบบและทุกสายหยุดจนกว่าจะกู้คืน ลูกค้าต้องรับเงื่อนไขนี้เป็นลายลักษณ์อักษร
- **Duo สลับเองเฉพาะฝั่งเสียง** เมื่อเครื่องหลักดับ Agent รับงานไม่ได้จนกว่าเราสลับแอปและฐานข้อมูลให้ และข้อมูลช่วงสั้น ๆ ก่อนเครื่องดับอาจหาย
- **ทุกรุ่น** เมื่อ FreeSWITCH ตัวใดดับ สายที่คุยอยู่บนตัวนั้นหลุด
- **ลูกค้าที่มี PBX เดิม** เชื่อมเข้ามาเป็น SIP trunk D-Contact ไม่ควบคุม PBX นั้นโดยตรง

## ต้องทำก่อนเปิดขาย

1. Load test Solo ที่ 35 สายและ Duo ที่ 70 สายบนเครื่องเดียว เพื่อยืนยันสเปกเครื่อง
2. ซ้อมสลับเครื่องของ Duo และกู้คืนของ Solo แล้ววัดเวลาจริง เพื่อใช้กำหนด SLA
3. ตรวจว่าระบบบันทึกเสียงเก็บไฟล์รูปแบบใดจริง เพื่อยืนยันขนาดดิสก์
4. เก็บตัวเลขต้นทุนในตารางข้างบน แล้วกำหนดราคา
5. กำหนดสเปกและวิธีคิดราคาของ Cluster
6. ตรวจข้อกำหนดทางกฎหมายของการให้บริการเบอร์โทรศัพท์ใน Cloud กับ provider และฝ่ายกฎหมาย
7. ทำชุดติดตั้ง on-prem ซึ่งยังไม่มี
8. ทำงานบันทึกเสียง (#845–#848) ที่พักอยู่ให้เสร็จ

รายการนี้เป็นบันทึกสำหรับวันที่ owner สั่งเริ่ม ยังไม่มีข้อใดอยู่ในแผนงานปัจจุบัน
