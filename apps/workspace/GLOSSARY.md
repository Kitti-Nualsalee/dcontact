# คำศัพท์ Workspace

## External softphone

แอปโทรศัพท์ที่รับผิดชอบการรับส่งเสียงและการเชื่อมต่อสายแยกจาก Workspace เช่น desktop app หรือ browser extension

## Softphone control

ส่วนที่ผู้ใช้ส่งคำสั่งควบคุมโทรศัพท์และดูสถานะสาย โดยไม่เป็นเจ้าของเสียงของสายเอง

## Control simulator

ตัวจำลองสำหรับทดลองปุ่มและลำดับสถานะของ Softphone control โดยไม่รับส่งเสียงและไม่สร้างงานหรือประวัติการโทรจริง
